## Descripción
Este repositorio se ha creado específicamente para la realización de la **Actividad Evaluable A4 (MF0490_3)** sobre control de versiones con Git y GitHub.

En este proyecto se aplican los siguientes conceptos y flujos de trabajo:
* Inicialización del repositorio local y configuración inicial.
* Creación y gestión de ramas (*branches*).
* Registro de cambios mediante *commits*.
* Sincronización con el repositorio remoto en GitHub.
